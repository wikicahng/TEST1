# VROID DESIGN ARCHIVE V2.2 — Loading / Preload

本版保留原有作品資料與版面，新增進站 Loading 與智慧預載。

## 啟動畫面會做什麼

1. 讀取 `data/works.json`
2. 預載首頁背景
3. 預載 `works.json` 中所有圖片
4. 預載影片 poster
5. 對每支 MP4 預載到可解碼首幀 / 可播放起始內容
6. 完成後進入網站
7. 網站開啟後，再把大型 MP4 一支一支於背景續載

進度百分比是「素材項目完成數 / 總項目數」，不是假的動畫百分比。

## 為什麼不在 100% 前完整下載所有 MP4？

影片可能很大。若強制等所有影片完整下載完，手機第一次進站可能需要下載數十到數百 MB。
V2.2 先確保影片已有可顯示的起始資料，再於背景續載，兼顧進站速度與點開影片時的反應。

## SKIP WAIT

等待超過約 4.5 秒後會出現 `SKIP WAIT`。
使用者可先進網站，尚未完成的預載仍會繼續。

## Save-Data

若瀏覽器啟用了省流量模式，網站會跳過「進站後完整背景影片續載」。
圖片與影片起始資料仍會依正常啟動流程載入。

## Lightbox

如果使用者在影片尚未緩衝完成前點開，會顯示 `BUFFERING MEDIA`，不再是空白畫面。

## 快取

V2.2 已把 CSS / JS 版本升為 `2.2.0`。
若 GitHub Pages 仍顯示舊版，可用：

`https://你的網址/?v=2.2`

測試。
